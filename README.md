# 📖 BibleTyping (성경 타자 연습 웹 애플리케이션)

## 📌 프로젝트 소개
**BibleTyping**은 사용자가 성경을 직접 타이핑하며 읽고, 자신의 진도와 타이핑 기록을 체계적으로 관리할 수 있는 웹 애플리케이션입니다. 
단순한 타자 연습을 넘어, RESTful API 연동 및 DB 저장을 통해 개인별 데이터의 연속성을 보장하며 직관적인 대시보드를 제공하는 데 중점을 두었습니다. 개발 전 과정에서 AI 어시스턴트를 적극 활용하여 코드의 품질과 개발 생산성을 높였습니다.

## 🛠 기술 스택
* **Backend:** Java, Spring Boot, MyBatis
* **Database:** MySQL
* **Frontend:** JavaScript (Vanilla JS), JSP, CSS
* **Architecture / API:** RESTful API
* **Data Management:** JSON / JS 모듈화 (`bibleData.js`)
* **AI Assistance:** Gemini, Gemini Code Assist (IntelliJ)

## ✨ 주요 기능 및 특징

### 1. 성경 데이터 모듈화 및 매핑
* 방대한 성경 데이터를 외부 JS 파일(`bibleData.js`)로 분리하여 화면 렌더링 성능 및 유지보수성 향상
* 영어 표준 약어(`bookCodeEn`)와 한글 약어(`bookCodeKo`)를 1:1로 매핑하여 체계적인 데이터 구조 확립

### 2. RESTful API 및 MyBatis 기반의 데이터 관리
* 타자 연습 실행 시 필요한 파라미터(권, 장 등)를 구조화된 REST API 규격에 맞춰 백엔드로 전송
* **MyBatis**를 활용하여 복잡한 SQL 쿼리를 효율적으로 관리하고, Spring Boot와 MySQL 간의 안정적인 데이터 통신 구현
* 사용자가 다시 접속했을 때 MySQL에 저장된 이전 기록을 조회하여 이어서 진행할 수 있도록 안정적인 진도 관리 기능 지원

### 3. 실시간 타이핑 통계 대시보드
* 사용자의 실시간 키 입력을 기반으로 타자 속도(WPM) 및 오타율을 정밀하게 계산
* 분석된 통계 데이터를 메인 대시보드에 직관적으로 시각화하여 학습 피드백 제공

### 4. 동적 모달 창 및 UI/UX 최적화
* **장문 연습 모달:** 메인 화면 위에서 자연스럽게 열리는 모달을 통해 몰입감 있는 타자 환경 제공
* **History API 연동:** 브라우저의 뒤로 가기 버튼과 동적 모달 창의 상태를 동기화하여, 비정상적인 접근이나 페이지 이탈 시 발생할 수 있는 데이터 유실 및 불편함 방지
* **직관적인 레이아웃:** 상단 헤더의 일관성 유지, 중앙 타이틀 배치, 직관적인 뒤로 가기 버튼 구성

### 5. AI 기반 개발 및 최적화
* **Gemini Code Assist:** IntelliJ 개발 환경에 통합하여 실시간 코드 자동 완성, 문맥 기반 리팩토링 및 신속한 디버깅 수행
* **Gemini 프롬프팅:** 복잡한 비즈니스 로직 설계 및 화면 구조화 과정에서 AI와의 대화를 통해 아이디어를 구체화하고 코드 퀄리티 향상

## 🏗 흐름도 (Data Flow)
1. 사용자가 메인 화면에서 특정 성경(예: 창세기, 요한복음) 선택
2. `bibleData.js`에서 매핑된 약어 코드를 기반으로 모달 창 렌더링
3. 타자 연습 진행 중 실시간으로 WPM 및 오타율을 계산하여 화면에 반영
4. 연습 완료 시, JavaScript Fetch API를 통해 설계된 RESTful 엔드포인트로 진행 상태를 전송(HTTP POST/PUT)
5. Spring Boot 컨트롤러에서 요청을 처리하고, **MyBatis 매퍼(Mapper)**를 통해 MySQL 데이터베이스의 사용자 진도 테이블 업데이트

## 🚀 향후 개선 사항
* 클라우드 환경(AWS 등)을 활용한 서비스 배포 및 인프라 구축
* 다중 사용자 동시 접속 시의 데이터 처리 안정성 및 MySQL 커넥션 풀 최적화
* 기간별 타자 속도 추이 및 누적 오타율을 보여주는 시각화 차트 추가
